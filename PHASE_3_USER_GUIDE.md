# ZEROX Phase 3 - Customer Dashboard User Guide

## Quick Start

### Accessing the Dashboard
1. Navigate to `your-app-url/dashboard` or click your profile avatar in the navbar
2. You must be logged in to access the dashboard
3. If not logged in, you'll see an authentication prompt

---

## Dashboard Sections

### 🔐 Profile Tab
**Manage your account information**

**What you can do:**
- View your name, email, and phone number
- Edit your name and phone number
- See your identity verification status
- View your membership tier (if applicable)
- View your creator rank and challenger points

**How to edit:**
1. Click the "Edit" (pencil icon) button
2. Update your information
3. Click "Save Changes" to confirm
4. Click "Cancel" to discard changes

---

### 📦 Orders Tab
**View and manage all your orders**

**What you can do:**
- See a complete history of all orders
- View order status with color-coded badges
- See order total and item count
- Track order progress with visual indicators
- Open detailed order information

**Viewing Order Details:**
1. Click on any order card to open the detailed view
2. See:
   - Full order status
   - All items ordered with quantities and prices
   - Subtotal, shipping, tax, and grand total
   - Shipping address
   - Animated timeline showing order progress
3. Actions you can take:
   - **Download PDF Invoice** - Download order invoice (pending configuration)
   - **Request Return** - Start a return process
   - **Request Refund** - Request a refund
   - **Close** - Close the detail modal

**Order Status Meanings:**
- **PENDING** - Order placed, awaiting confirmation
- **PROCESSING** - Order is being prepared
- **SHIPPED** - Order is on its way
- **DELIVERED** - Order has been delivered
- **CANCELLED** - Order was cancelled

---

### 🗺️ Addresses Tab
**Save and manage shipping addresses**

**What you can do:**
- Add new shipping or billing addresses
- Edit existing addresses
- Delete addresses you no longer need
- Mark addresses as default or billing

**Adding a New Address:**
1. Click "+ ADD ADDRESS" button
2. Fill in all required fields:
   - Full Name
   - Street Address
   - City
   - State
   - ZIP Code
   - Phone Number
3. Check "Default Address" if you want this as your primary shipping address
4. Check "Billing Address" if this is your billing address
5. Click "SAVE" to create the address

**Editing an Address:**
1. Click the edit (pencil) icon on the address you want to modify
2. Update the fields
3. Click "SAVE" to confirm changes

**Deleting an Address:**
1. Click the trash icon on the address
2. The address will be immediately deleted
3. Cannot be undone, but you can add it again

**Address Tips:**
- You can have multiple addresses saved
- Set one as default for faster checkout
- Separate billing and shipping addresses if needed

---

### ❤️ Wishlist Tab
**Save items you want to buy later**

**What you can do:**
- View all items in your wishlist
- Move items to your shopping cart
- Remove items from your wishlist
- See count of saved items

**Managing Wishlist Items:**
1. View your saved items in a clean list
2. **Add to Cart** - Click the button to add item to shopping cart
3. **Remove** - Click the X button to remove from wishlist

**Adding Items to Wishlist:**
- From product pages, click the heart icon ("Save to Wishlist")
- Items are automatically synced across your devices

**Wishlist Tips:**
- Wishlist persists across sessions
- Use it to make shopping lists
- Share wishlist with friends (coming soon)

### ⚙️ Settings Tab
**Manage your account preferences**

**What you can do:**
- Add and remove payment methods
- Manage notification preferences

**Payment Methods Section:**
- Click "+ ADD CARD" to add a new payment method
- View all saved cards (showing last 4 digits)

**Other Settings:**

### 🔒 Security Tab
**Protect your account**

**What you can do:**
- Change your password
- Enable two-factor authentication
- View active sessions/devices
- Check login activity
- Manage privacy settings
- Delete your account (irreversible)

**Change Password:**
1. Click "CHANGE" button
2. Enter your current password
3. Enter new password twice
4. Click confirm

**Enable Two-Factor Authentication (2FA):**
1. Click "ENABLE" button
2. Follow the setup wizard
3. Scan QR code with authenticator app
4. Enter verification code
5. Save backup codes in safe place

**Active Sessions:**
- See all devices accessing your account
- Shows device type and current location
- Can remotely log out from other devices

**Login Activity:**
- View recent login attempts
- See timestamps and locations
- Identify suspicious activity

**Delete Account:**
⚠️ **WARNING: This is permanent and cannot be undone**
1. Click "DELETE" button
2. Confirm you want to delete
3. All your data will be permanently removed
4. You can create a new account afterwards

## 🛒 Shopping Cart

**Access your shopping cart:**
- Click the floating cart button in the bottom-right corner
- See all items you've added
- View cart total with breakdown

**Cart Features:**
- **Update Quantities** - Click + or - to adjust quantities

- **Apply Coupon** - Enter coupon code (e.g., "SAVE10")

**Coupon Codes:**
- Try "SAVE10" for 10% off

- Applied automatically when you click "Apply"

## 🔄 Returns & Refunds

**Submitting a Return:**
1. Open order details
2. Click "RETURN" button
3. Select return reason from dropdown
4. Upload images of damaged items (optional)
5. Click "SUBMIT REQUEST"
6. Track return status in history

**Submitting a Refund:**
1. Open order details
2. Click "REFUND" button
3. Select refund reason
4. Click "SUBMIT REQUEST"
5. Receive confirmation and timeline

**Return Status Timeline:**
- ⏳ **Pending** - Waiting for approval
- ✅ **Approved** - Return approved, waiting for shipment
- 🚚 **In Transit** - Your return is being shipped
- 📦 **Received** - We received your return
- ✓ **Processed** - Return processed, refund issued
- ❌ **Denied** - Return was not approved

**Tracking Returns:**
- View all past returns in the Returns section
- See status updates in real-time
- Receive notifications at each step

## ❓ FAQ

**Q: Can I change my email address?**
A: Currently no, but you can contact support for assistance.

**Q: How long do returns take?**
A: Returns typically take 10-15 business days after we receive the item.

**Q: Can I cancel my return?**
A: Yes, you can cancel pending returns from the Returns section.

**Q: Is my payment information secure?**
A: Yes, we use Stripe for secure payment processing. We never store full card numbers.

**Q: What if I don't receive my order?**
A: Check the tracking information. If still missing after tracking date, contact support.

**Q: Can I export my data?**
A: Yes, you can download your data from account settings (coming soon).

**Q: How do I delete my account?**
A: Go to Security tab, scroll to bottom, click "Delete Account". This is permanent.
